# STM32F103C8T6 电机控制接线文档

## 硬件清单

| 器件 | 数量 | 备注 |
|------|------|------|
| STM32F103C8T6 开发板 | 1 | 最小系统板 |
| 直流减速电机（带编码器） | 2 | 6V~12V |
| 电机驱动模块 | 2 | TB6612 |
| 编码器电源 | 1 | 5V（给编码器供电） |

## 引脚分配表

### PWM输出（TIM3）- 电机速度控制

| STM32引脚 | 功能 | 连接到 | 说明 |
|-----------|------|--------|------|
| **PA6** | TIM3_CH1 | 左电机PWM输入 | 左轮速度控制 |
| **PA7** | TIM3_CH2 | 右电机PWM输入 | 右轮速度控制 |

### 编码器输入（TIM1/TIM2）- 电机测速

| STM32引脚 | 功能 | 连接到 | 说明 |
|-----------|------|--------|------|
| **PA8** | TIM1_CH1 | 右电机编码器A相 | 右轮测速 |
| **PA9** | TIM1_CH2 | 右电机编码器B相 | 右轮测速 |
| **PA0** | TIM2_CH1 | 左电机编码器A相 | 左轮测速 |
| **PA1** | TIM2_CH2 | 左电机编码器B相 | 左轮测速 |

### GPIO输出 - 电机方向控制

| STM32引脚 | 功能 | 连接到 | 说明 |
|-----------|------|--------|------|
| **PB0** | GPIO_Output | 左电机IN1 | 左轮方向控制 |
| **PB1** | GPIO_Output | 左电机IN2 | 左轮方向控制 |
| **PB10** | GPIO_Output | 右电机IN1 | 右轮方向控制 |
| **PB11** | GPIO_Output | 右电机IN2 | 右轮方向控制 |
| **PB12** | STBY | 驱动模块STBY | 使能引脚（高电平有效） |

### 其他必要连接

| 功能 | 连接到 | 说明 |
|------|--------|------|
| **PD0** | 8MHz晶振 | HSE输入 |
| **PD1** | 8MHz晶振 | HSE输出 |
| **PA13** | SWDIO | 调试接口 |
| **PA14** | SWCLK | 调试接口 |

-----------         --------------
VMOT    ────────────  电池正极（6-12V）

AIN2    ────────────  PB1

STBY    ────────────  PB12

```

```

BIN2    ────────────  PB11

## 方向控制逻辑

| PB0 (IN1) | PB1 (IN2) | 左电机状态 |
|-----------|-----------|------------|
| 0 | 0 | 停止 |
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 1 | 1 | 停止（刹车） |

| PB10 (IN1) | PB11 (IN2) | 右电机状态 |
|------------|------------|------------|
| 0 | 0 | 停止 |
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 1 | 1 | 停止（刹车） |

## 注意事项

1. **电源要求**：电机驱动需要独立供电（6-12V），STM32使用5V供电
2. **共地**：所有模块的GND必须连接到一起
3. **STBY引脚**：必须拉高才能使能电机驱动
4. **编码器电源**：编码器使用5V供电，不要接到3.3V
5. **调试接口**：PA13(SWDIO)和PA14(SWCLK)用于SWD调试，不要用作其他功能
